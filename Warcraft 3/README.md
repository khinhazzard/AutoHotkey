# Warcraft 3 AutoHotkey Scripts

AutoHotkey scripts created to add custom hotkeys and controls for Warcraft III.

## Scripts

### ALLinOne v1
Combines several Warcraft III hotkey functions into one script:
- Disables mouse wheel scrolling
- Blocks Ctrl+S and Ctrl+M game sound/mute shortcuts
- Toggles health bars with CapsLock

### ALLinOne v2
Expanded version of ALLinOne v1:
- Disables mouse wheel scrolling
- Blocks Ctrl+S and Ctrl+M game sound/mute shortcuts
- Remaps Alt+` to Backspace for Town Hall cycling
- Remaps Alt+Q/W/A/S/Z/X to numpad keys for inventory
- Toggles health bars with CapsLock
- Forces NumLock on

### ALLinOne v3
Updated version of ALLinOne v2:
- Disables mouse wheel scrolling
- Ctrl+S sends the Y key instead of the game's save/mute shortcut
- Blocks Ctrl+M
- Remaps Alt+` to Backspace for Town Hall cycling
- Remaps Alt+Q/W/A/S/Z/X to numpad keys for inventory
- Toggles health bars with CapsLock
- Forces NumLock on

### ToggleHPBars
Standalone health bar toggle:
- CapsLock toggles Warcraft III health bars
- Prevents the CapsLock indicator from turning on

### BlockSoundandMusicHotkeys (CTRL_S_and_M)
Blocks Warcraft III sound and music hotkeys:
- Ctrl+S
- Ctrl+M

### CycleTownHall (alt`)
Remaps Alt+` to Backspace for Town Hall cycling in Warcraft III.
